# Decide whether another agent helps

Read when choosing a new session or when coordination is delaying delivery. Delegate when missing expertise, required independence or a substantial parallel deliverable justifies briefing, repeated source loading, worktree preparation, waiting, hand-in and integration. Make this judgment directly, without another agent, approval form or mandatory ledger entry.

Routine source inspection, applying a qualified derivation, local text corrections, mechanical integration, established checks and records usually stay with the principal or current owner. Before escalating, identify what remains unresolved:

- Merge established meanings when edits overlap. A textual overlap alone does not establish a scientific disagreement.
- Check public uses and existing decisions before treating an unused internal path or a stale option description as a capability choice. Describe accepted behavior and record compatibility consequences in change notes. An unresolved loss of useful public capability needs a substantive decision.
- Judge a validation change by its scientific premises and actual resource consequences. A conservative working estimate is not a hard budget. Keep applicable evidence within authorized scope, and honor explicit human limits.

For example, an independent mathematical review establishes that a displayed radius includes two bias components, while a guide names only one. The principal or current reviewer corrects the guide and label, then checks the affected rendering using that qualified result.

Batch related questions for the same source and decision. A review can serve hand-in, acceptance and final review within its actual coverage. Local corrections need checks of the affected content. Once required reviews pass, finish wording and records directly rather than starting another round for a completion report.

Fresh-session rules govern necessary requests and cannot be bypassed by reopening an ended session. New derivations, changed numerical premises and required independent scientific acceptance still need the appropriate expert. Unresolved capability choices, material default cost increases and consequential disagreements go to the counselor or user within their authority. Stop when the decision and its affected evidence are settled.
