# Optional Research-STORM-style inquiry

Use this reference for a broad investigation that benefits from distinct question
lanes and an evolving synthesis. It is not required for a narrow source check,
nor is another retrieval round sufficient reason to load a full workflow.

STORM's perspective-guided inquiry and outline refinement originated in knowledge
curation; their use here does not establish scientific correctness. Co-STORM's
user steering is an optional interaction pattern, not a required approval round.

## Adaptive inquiry

Choose lanes from unresolved questions, such as closest prior work, historical
terminology, theorem assumptions, implementation costs, experimental comparison,
or contradictory results. Combine lanes that would retrieve the same evidence.
There is no minimum number of perspectives, agents, or retrieval rounds.

Retrieve and inspect evidence, then decide the next question from what changed.
Independent searches may run together; dependent checks follow their sources.
Use primary sources for load-bearing claims and retain compact records when they
help later synthesis. Do not create parallel claim, source, concept, contradiction,
and lineage maps unless their distinct use justifies them.

Reconsider the search when questions repeat, evidence is unused, a central
assumption is shared without support, or a contradiction remains unresolved.
Alternate terminology and citation paths are useful when they could locate a
missed source. This reconsideration can happen in the same agent; a moderator
role or an extra round is not mandatory.

Keep an outline provisional and revise it to reflect the evidence rather than
forcing sources into it. Draft the requested prose when sufficient evidence is
available. Ask the user to choose branches only when they requested interactive
exploration or their preference materially changes the work.

## Stop conditions

Stop or narrow a branch when the question is answered to useful precision,
retrieved evidence is redundant, the branch is outside scope, or the unresolved
issue requires a different kind of work. State an access or coverage limit when
it affects the conclusion. Do not exhaust every possible query family simply to
declare completion.
