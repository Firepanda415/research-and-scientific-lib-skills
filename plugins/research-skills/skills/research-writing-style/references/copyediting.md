# Copyediting scientific prose

Use this reference for requested sentence-level or paragraph-level writing review. Preserve the scientific argument and author voice. A copyedit does not become a referee review, submission-readiness audit, or new experiment campaign.

## Preserve the local voice and edit scope

- Read nearby accepted prose from the same section. Match technical vocabulary, claim order, first-person practice, hedging, and transition density. If there is no stable sample, state that the voice model is uncertain.
- For a copyedit, identify a concrete defect before a nontrivial edit, such as grammar, ambiguity, redundancy, unsupported scope, or wrong argument order. A requested style or voice rewrite can change phrasing and sentence organization without first finding a factual or grammatical defect. Treat that request as a rewrite and preserve the claims. When the user requests edits and says a draft's organization, notation, or layout is unreliable (for example, an unrevised student draft), treat the request as a structural rewrite of the requested passage that keeps its verified claims, values, citations, and scope.
- Within a copyedit, use the smallest intervention that fixes the problem. Preserve the sentence skeleton, claim order, technical nouns, characteristic verbs, and epistemic strength unless they cause the defect. Do not rewrite an entire paragraph to replace a suspected detector word.
- As an internal review heuristic, reconsider a copyedit that changes roughly more than 10--15% of a paragraph's running words or rearranges its clauses. Reduce the edit or label it `structural rewrite` and present it as an optional alternative unless the user already requested a rewrite. This is not a quota or a new permission requirement.
- Label a revision set as `copyedit`, `structural rewrite`, or `new prose`. Do not present a changed argument or newly supplied content as a copyedit.

## Check meaning and clarity

Identify the paragraph's claim, evidence, qualification, comparison direction, and citations before changing it. Read the relevant definitions and build a compact symbol/term map for the objects being edited. Reuse established names and permit defined field-specific acronyms. Repeat definitions where an independently read abstract or caption needs them. Batch searches where useful and check touched terminology for unintended aliases; a separate search for every noun phrase is unnecessary.

Remove clutter only when it adds no meaning. Keep result-sensitive qualifications and established technical phrases. Name the actor when accountability matters, but keep passive voice when it appropriately emphasizes the object or operation. Repair ambiguous attachment, buried arguments, and confusing structure. Sentence length and rhythm guide judgment rather than quotas. For paragraph-level rhetoric or structure work, use [manuscript prose](manuscript-prose.md).

A detector label alone does not establish authorship or a writing defect. In an ordinary copyedit, judge flagged passages using the same editorial criteria as other prose. For an explicit request to rewrite against detector results, apply [detector evaluation](detector-evaluation.md), produce actual alternatives, and measure them when authorized access is available. Keep precise, necessary language and check that the changes preserve meaning.

Flag a suspected scientific error separately and inspect the relevant source before changing its meaning. A clear sentence can stay even if it breaks a soft style heuristic. House style is editorial; severity follows a change in meaning or a real comprehension barrier. The [shared final gate](../SKILL.md) requires checking that values, units, signs, indices, quantifiers, citations, comparisons, and qualifications still support the same claims. Token or citation diffs alone do not prove semantic equivalence.

## Deliver the requested edit

For source-document prose or math, apply [source layout](source-layout.md). For suggestions the user will paste manually, also read [revision feedback](revision-feedback.md) and apply its current-file, exactly-once full-span anchor and complete-text contract. For authorized direct edits, apply and verify the file without a separate manual replacement package. Combine applicable checks within the parent's mandatory review stage after drafting or editing. Each criterion does not need its own pass or report. Review-only requests do not authorize file changes or a full rewrite.
